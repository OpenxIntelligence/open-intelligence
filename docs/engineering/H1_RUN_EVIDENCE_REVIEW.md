# From a completed fictional brief to independent verification

In Investigations, open a completed background brief on a current saved source question. **Check saved passages** loads the existing authorized evidence packet; **Check saved citations** loads current catalog link permissions. Choose one entry and select **Return to review inbox**. The receipt appears under the brief and in the existing review inbox. An uncertain response can be recovered by reopening the same run and selecting the same entry again. Reopening or retrying requires current authorization.

The authored-passage choice verifies one human-authored assessment, its original evidence version, human display rights, and the exact literal quote, offset and hash. A catalog choice only verifies a bibliographic record's identity, version and permitted metadata. Neither operation appraises whether the evidence supports the question. The source-only worker does not receive the quote or catalog metadata; no model executes, and the handoff is a nonterminal return, not clinical review.

The existing review owner retains one immutable receipt per run and selection. Its audit event binds the completed result digest, source fingerprint and the checked evidence references; queue-only readers receive no passage or title. The server rechecks the actor, purpose, active case, immutable run artifact, original source, exact evidence and current permissions on every attempt, including retries. Changed sources, withdrawn rights or a superseded selection cannot authorize another return. This bounded H1 consumer advances #102 and #103; broader evidence retrieval, scientific verification, clinical judgment, production identity and deployment are separate work.
