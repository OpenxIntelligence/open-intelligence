## Integrated behavior and boundary fixes

Current Journey source statements and historical contexts in Journey **and Records** can show exact source classifications with retained original states, source IDs, hashes, concept versions and snapshot fingerprints. Missing, negative, pending and indeterminate remain distinct. A reported entry does not infer disease presence, normality, professional review or model execution.

The donor semantic reader required a loaded current Journey model even for history. The unified reader instead binds the request to its actual context: the current World Model, a Journey historical snapshot, or the authorized Records index plus its exact historical snapshot. It checks patient/read generation, source object identity and historical membership. Disconnect, dismissal, refresh, patient change or revoked access withholds late responses; rejected late bodies are cancelled. Source-read denial clears original, current and historical presentations. Independent original-read denial permits authorized historical classifications.

Historical classifications now use the source owner's strict RFC3339/microsecond receipt parser. Overprecision, invalid calendar, naive and future boundaries fail before database access for both historical endpoints. No new schema, grant, runtime dependency or canonical state owner is introduced. The semantic contract remains a deterministic source projection, not an inference engine.
