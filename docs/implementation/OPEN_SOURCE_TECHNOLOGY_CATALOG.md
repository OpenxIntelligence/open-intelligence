# Open-source technology catalog

**Decision for this build:** retain the existing Python/FastAPI/PostgreSQL 16 and React/Vite/TypeScript stack. The shared patient ingress and dependency verification increments add first-party code and no runtime packages. The selection criterion is whether a component improves a reproducible patient or research workflow within its rights and operating boundaries.

**Decision vocabulary.** Retain applies to existing scoped engineering use. Evaluate means a candidate has a specific test to run. Defer and reject apply to the identified use and artifact. An upstream source snapshot is evidence about its contents on that revision. It is not a supplier warranty, vulnerability assessment, performance measurement or complete binary SBOM. If a review supplies a release tag, preserve the resolved commit and actual artifact digest before adding a dependency.

**Comparison method.** Assess technical fit, license compatibility, maintenance activity, security, interoperability, performance, operational cost and sustainability against the relevant use. The infrastructure study uses eight separate triage marks; the clinical and science studies describe concrete task fit, blockers, evidence and alternatives. For any field without measured evidence, record unknown. Compare with a no-new-dependency baseline using the same fictional inputs, environment, pass criteria, resource budgets and reviewers. A tool-level rank cannot override a failed rights, isolation, correctness or clinical acceptance gate.
