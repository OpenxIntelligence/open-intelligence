# Open-source technology catalog and foundation decisions

**5 November 2026 · recommendation for the connected synthetic H1 application.** Retain Python/FastAPI/Pydantic, SQLAlchemy/Alembic/PostgreSQL and React/TypeScript/Vite. Use existing source custody, scoped access checks, command receipts and test/restore harnesses. **No dependency installed or selected for newly integrated use by this catalog.** No framework replacement, shared cache, broker, vector database, second patient store or Kubernetes cluster is justified by measured H1 demand. Next.js and vector retrieval remain excluded from H1.

The authoritative [architecture decisions](ARCHITECTURE_DECISIONS.md) and [exact application rights/lock register](LICENSE_AND_SBOM_REGISTER.md) distinguish accepted main, candidate code and research. The application set was read from [#540](https://github.com/OpenxIntelligence/open-intelligence/tree/299cfb54df8259c6d72ddd88f3e0c08ca3dda3f4) and [#542](https://github.com/OpenxIntelligence/open-intelligence/tree/80660730df2b8a819aa37215e39bc7f9af55c0f7), not inferred from upstream releases. Open [#532](https://github.com/OpenxIntelligence/open-intelligence/pull/532), the [prior strategy](../project-state/TECHNOLOGY_STRATEGY.md), [149-row agentic intake](../research/agentic_infrastructure_intake_2026-11-04.csv) and its [16 prior license snapshots](../research/agentic_infrastructure_license_evidence_2026-11-04.json) are complementary. A license blob alone does not identify a deployable artifact.

## How to use the 85 upstream infrastructure and application rows

Links identify an official upstream, screened release **or full source commit**, exact-revision license and build/dependency input. The source date is the release publication date where the publisher exposed it, otherwise a commit date. Repository push dates and archive flags were checked separately; a push can be documentation rather than a supported release. No new executable packages, commercial production path, image, browser binary, chart, model or data asset were audited by installing every candidate. “Existing tooling only” means that the project invokes that tool class in development/CI, **not** that the upstream comparison version is installed or approved. Monorepo tags identify source snapshots; the component's package version is given where it differs.

“Retain” recognizes an existing decision. “Evaluate” permits research/design of a bounded comparison, not installation. “Defer” has no present workload justification. “Hold/Reject” prevents inclusion under this scope. Integration effort **L/M/H** is our estimate (in-process/tool-only / additional integration changes / separate stateful service or governance). The eight per-row scores are a triage opinion in order: **current technical fit / source-license fit / maintenance signal / security / interoperability / measured performance / operating simplicity / sustainability for this project**. 3 strong, 2 conditional, 1 weak, 0 closed/archived; **? = not measured or reviewed**. Maintenance uses archive state and recent upstream push as one limited signal. Security and performance are deliberately unscored until an exact artifact, advisory snapshot and representative isolated benchmark exist. Never average away a rights block.

The license column screens the linked code scope. In the absence of contrary file terms, MIT requires retaining copyright/permission notices; BSD requires preserving notices/disclaimers (3-Clause also forbids implied endorsement); ISC/PostgreSQL require preserving their notices; Apache-2.0 adds license, applicable attribution/NOTICE, changed-file and patent provisions. These source grants generally allow commercial use and redistribution under those conditions. For GPL/LGPL/MPL/AGPL, commercial use and permission to distribute are separate from satisfying the relevant source, modification, boundary or network-use duties. BSD-style or Apache labels cannot clear supplier binaries, dependency trees, trademarks, datasets, hosted services, models or plugins. Mixed/source-available entries have no blanket commercial or redistribution determination; see [operation and artifact controls](LICENSE_AND_SBOM_REGISTER.md).

The selected operation and license path must be explicit; no Redis commercial products or hosted terms are selected. Valkey's two copyright sets in [COPYING](https://github.com/valkey-io/valkey/blob/29173b67508b2de4c0f0ed551f3b47cf19fc3ca8/COPYING) are both BSD-3-Clause. That does not inventory jemalloc/Lua or the image.
* **Worker and observability licenses.** Dramatiq [LGPL-3.0 text](https://github.com/Bogdanp/dramatiq/blob/3ccb3562cf4169b7eb6fd64746790c9a88d1cb89/COPYING.LESSER) supplements its GPLv3 base, with [upstream LGPL-3.0-or-later declaration](https://github.com/Bogdanp/dramatiq/blob/3ccb3562cf4169b7eb6fd64746790c9a88d1cb89/setup.py); do not label it simple GPL or MIT. RabbitMQ's allocation between [MPL core](https://github.com/rabbitmq/rabbitmq-server/blob/24d5157cd415ef396c8ecd40a2d08c4d7ad3da9f/LICENSE-MPL-RabbitMQ) and some Apache files does not cover third-party plugins. [Grafana](https://github.com/grafana/grafana/blob/752e3462ff71a43a5c1fb62d00a482fa2dc0ee6a/LICENSING.md) and [Loki](https://github.com/grafana/loki/blob/d3b4a2f76bfc5625abee7ceb00b8896fa3c31549/LICENSING.md) default to AGPL-3.0-only with defined Apache directories and separate third-party terms. Collector's root go.mod explicitly does not build an official binary; qualify the exact compiled distribution and configured receivers/processors/exporters.
* **Storage and deployment.** [MinIO's entrypoint](https://github.com/minio/minio/blob/9e49d5e7a648f00e26f2246f4dc28e6b07f8c84a/main.go) says AGPL-3.0-or-later; the repository reported archived and its screened release is from October 2025. A maintained replacement, commercial product or fork is a different artifact. [lakeFS v1.88.0](https://github.com/treeverse/lakeFS/blob/ef369be652b8110605ba19b770fddb8a337e8d20/LICENSE) carries BUSL-1.1 with an internal/unmodified use grant naming **1.87.0** as licensed work. Obtain upstream clarification before relying on this version; block default commercial/institutional distribution. [Terraform](https://github.com/hashicorp/terraform/blob/ff6329e4c2a159b46ec2b73d36bfa3d0ef6560c9/LICENSE) uses BUSL-1.1 with a competitive-offering restriction and change date; not a generally permissive core dependency. OpenTofu is MPL-2.0; providers/modules have separate scopes. Ceph's [file-by-file register](https://github.com/ceph/ceph/blob/26796b20faeefefaea0605aa2f65269e0c7e8490/COPYING) includes LGPL, GPL, BSD, CC-BY-SA and other terms. [HDF5](https://github.com/HDFGroup/hdf5/blob/49df1b4e5ca4108d56e80f06321a749da1535268/LICENSE) describes BSD-3-Clause, contributions of enhancements and additional package notices. Apache Arrow's [nested notice file](https://github.com/apache/arrow/blob/dff77c5d4dced6be5209a6299b7cebe6131125e3/LICENSE.txt) documents third-party portions including RapidJSON subpaths; inspect the actual shipped build.
* **Identity and enterprise splits.** [authentik](https://github.com/goauthentik/authentik/blob/4ec0d19b98da3c329781894cd550da95d3033954/LICENSE) separates MIT code/client JS, CC-BY-SA-4.0 website and [enterprise license](https://github.com/goauthentik/authentik/blob/4ec0d19b98da3c329781894cd550da95d3033954/authentik/enterprise/LICENSE); [Infisical](https://github.com/Infisical/infisical/blob/d040ecd84bb7b1708929f31372331d7c4dc03fa0/LICENSE) separates non-EE MIT and per-EE terms. An ISC label in the latter's backend package metadata is not a grant for the whole server. [AG Grid](https://github.com/ag-grid/ag-grid/blob/0bfa458d832add005365c62732d613f6dd34b544/LICENSE.txt) identifies Community MIT and Enterprise commercial; isolate actual packages/assets. [Semgrep CE](https://github.com/semgrep/semgrep/blob/ac37d1f6e47b17648b8f854d6e2f2d72fade2567/cli/pyproject.toml) declares LGPL-2.1-or-later; rule packs and hosted services are a separate procurement/rights decision.
* **Checked dependency edges, not complete closures.** OTel Collector service lists [client_model 0.6.3](https://github.com/prometheus/client_model/blob/v0.6.3/LICENSE) (Apache-2.0) and [google/uuid 1.6.0](https://github.com/google/uuid/blob/v1.6.0/LICENSE) (BSD-3-Clause). OPA lists [xxhash 2.3.0](https://github.com/cespare/xxhash/blob/v2.3.0/LICENSE.txt) (MIT). Syft and Grype list [cyclonedx-go 0.12.0](https://github.com/CycloneDX/cyclonedx-go/blob/v0.12.0/LICENSE) (Apache-2.0). Keycloak's build declares [Quarkus 3.40.1.1](https://github.com/quarkusio/quarkus/blob/3.40.1.1/LICENSE) (Apache-2.0). Restic lists [Google Cloud storage 1.62.2](https://github.com/googleapis/google-cloud-go/blob/storage/v1.62.2/LICENSE) (Apache-2.0 at repository root). These exact dependency license files were inspected; none establishes that every declared target/feature ships or permits sending content to the named provider.

Before a new package progresses from “evaluate,” nominate an owner, a bounded pass/fail requirement and an exit path. Freeze the exact artifact/platform and verify signatures/digests; inspect artifact notices, selected dependency edges and native linkage, scanner DB/time and advisories; distinguish OSS extensions from paid services and data assets. Run the stated denial, recovery, latency and cost tests on original fictional cases. For a conditional license or new distribution, take the concrete scope to the rights reviewer.
