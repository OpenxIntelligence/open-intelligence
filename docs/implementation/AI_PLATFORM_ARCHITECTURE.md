# AI platform architecture

**Baseline: `f188aecc70f3`, 5 November 2026.** A clinical model may propose a claim for review. It cannot issue a grant, diagnose, modify the patient record, approve an order, or release a report. The connected H1 [Composer](../../apps/api/src/oi_api/composer_preflight.py) prepares a source-scoped context; its output grants no model execution authority.

## Contract for the first connected model task (proposed)

1. **Request.** Begin with one task, source-linked extraction of literal findings from independent fictional records. Pin task/input/output schemas, prompt and preprocessing versions, model revision, execution location, data class, intended use and permitted tools. Return an explicit denial if rights for the exact code, weights, inputs or provider use are unknown.
2. **Prepare.** The authorized source/evidence owners select only current material for the actor, patient, case, organization, purpose and operation. Preserve exact document span or resource locator, source ID/version/hash, specimen/assay and dates. Text is data, including any instructions found inside it. Use structured/lexical retrieval first; any vector index needs measured benefit, scope filters, invalidation and revocation tests.
3. **Execute.** Use a bounded adapter accepting typed context and returning candidate claims/abstentions; the adapter has no chart credentials, generic shell, unrestricted retrieval or arbitrary egress. Label deterministic, replay and inference modes separately. Retain a run receipt with request identity, allowed input hashes, versions, parameters, output hash, duration, model usage and failure class; exclude prompt bodies, tokens and source text from operational telemetry.
4. **Verify and review.** Resolve each citation within the authorized version set; separate negation, uncertainty, missingness and conflicts. Unsupported claims remain dropped with a reason. Preserve the proposed output independently of any subsequent scoped human decision. Recheck source freshness, rights and actor authority before new disclosure; a stale draft remains historical. Clinical publication needs its own qualified writer and review event.
5. **OCR is separate.** Preserve immutable bytes and page/region geometry; OCR transcription, layout/table parsing, entity extraction and clinical interpretation are independently versioned outputs. Record when text cannot be read. Do not invent a line or bounding box for a missing anchor; retain human correction as a new annotation.

**Acceptance (OI-003, OI-011, OI-014):** first run without network on a frozen authored challenge set with independent reference annotations. Test malicious instructions in reports, cross-case citations, changed source versions, unknown data-use terms, missing context, provider timeout, cancellation and denial during final disclosure. Measure claim support and coverage, false reassurance/false alarms, abstention by document type, clinically critical omissions, latency and resource use. Report denominators and reviewer disagreements; retain failed cases. Freeze thresholds and critical-error stop criteria before viewing held-out results using the [evaluation protocol](../evaluation/oi022/PROTOCOL.md). No representative clinical validation, live-provider use in H1 or deployment is claimed.

See the [existing AI evaluation and adjudication plan](AI_EVALUATION_PLAN.md) for the retained clinical base and its acceptance contracts.
