**Decision, 5 November 2026.** Retain the first-party FastAPI/PostgreSQL identity, original-source and authorization owners. Support is described at the level of a transaction, source format, profile and revision—not a blanket “supports FHIR/DICOM” badge.

## Adapter boundary and proof

1. **Admission.** Authenticate and resolve trusted sending organization, interface configuration, case binding, allowed operation, purpose and current authority before accepting a bounded source. Enforce size, count, depth, content type and time/memory limits before or during decode. Refuse arbitrary URLs, DTD/entities, recursive archives and untrusted transfers. A Patient.id, PatientID, source organization string, national identifier, OAuth scope or matching demographics is never sufficient to choose the canonical patient.
2. **Validation and mapping.** Only a named, versioned profile is eligible. Validate resource cardinality, types, mandatory references and local extensions; keep original bytes, sending identifiers, original authority, transform version and a loss/unsupported-field receipt. Do not silently drop unknown clinically relevant fields. A structural pass, terminology membership, dimensional compatibility and clinical validity answer different questions. If terminology or mapping is unavailable, return an explicit unverified/unmapped state; do not present it as validation.
3. **Commit.** Delegate a single transaction to the canonical owner with action-specific grants, idempotency key plus digest of intent, current predecessor check, qualified binding and final authority. Replays recover the original receipt or return conflict for changed intent. Deterministic refusal is not an ACK of clinical acceptance. Only persist quarantined content under an explicit authorized quarantine/retention policy, with no assertions attached to the patient.
4. **Read and disclose.** Derive patient views from canonical source versions. Re-evaluate permission, consent restriction, purpose, current case and source rights for metadata, bytes, pixels, individual frames, export files, audit and asynchronous jobs. Scope URLs and browser caches; avoid origin-agnostic bearer forwarding and ambient archive credentials. Egress uses an explicit allowlist; comparisons and validation start offline with fictional data.
5. **Qualify end to end.** Include valid/invalid profiles, unsupported elements, two same-named patients/issuers, two specimens on one date, nested or dangling references, replay after timeout, successor versus repeat sample, authority loss mid-response, worker crash, corrupted bytes and restored historical reads. Test the exact production-shaped input limits, render paths and cache boundaries. Compare round-trip content and provenance, including legitimate losses, not byte-identical JSON serialization. Do not claim conformance without an independent test package/fixture corpus, result report and approved CapabilityStatement for the actual server behavior.

## Document processing and radiology milestones

Treat a file as four separately attributable things: (1) immutable original/version and access receipt, (2) parser/OCR-derived rendition, (3) typed extraction proposal, and (4) reviewed interpretation if authorized. Record tool/weight/config hashes, page index and page-box coordinates with coordinate origin, page rotation/crop and transform, text offsets with normalization convention, table/row/column or FHIR pointer, selected quotation and source hash. A tool upgrade creates a new rendition; prior annotations remain anchored to their original rendition. OCR confidence is engine-specific and is never a credential or substitute for a reviewer. No network model downloads, external clinical data or redacted replicas of real patients.

First qualify a synthetic native report with multi-column text, a page break, reference interval and amended unit; then a rotated scanned table and a report with two specimens. Show originals and highlights side by side. Refuse illegible digits, misplaced decimal or units, row shifts and ungrounded extraction; record abstention and handoff. Evaluate per-analyte field accuracy plus critical errors (wrong patient/specimen, transposed value/unit, polarity reversal, stale version), independent adjudication and coverage by document class/language.

Imaging qualification first covers secure study/series browsing and a source-linked review path. Prove correct SOP/frame and report lineage, an isolated unauthorized-series request, mid-request permission loss, unsupported SOP/transfer syntax, duplicate/reused UID, conflicting dates and bounded restore. Next add modality-specific rendering, explicit geometry, signed source reports, prior comparisons and annotations with reader/time/version. Lesion identity, response criteria, diagnostic display and ML interpretation require distinct evaluation; use research status for research derivations.
